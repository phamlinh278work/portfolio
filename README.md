# Portfolio — Phạm Thùy Linh

Hồ sơ năng lực Business Analyst, song ngữ Việt / Anh.

Trang: https://phamlinh278work.github.io/portfolio/

Trang đặt thẻ `noindex` nên không xuất hiện trên kết quả tìm kiếm — chỉ người có link mới xem được.

## Cấu trúc

- `index.html` — toàn bộ trang (HTML + CSS + JS nội tuyến)
- `img/` — ảnh chụp màn hình từ hai ứng dụng đang chạy thật

## Sửa nội dung

Sửa `index.html` rồi commit và push lên nhánh `main`; GitHub Pages tự xuất bản lại sau khoảng một phút.
Mỗi đoạn nội dung có hai phiên bản: `class="vi"` (tiếng Việt) và `class="en"` (tiếng Anh) — sửa thì nhớ sửa cả hai.
